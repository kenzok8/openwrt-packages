### v1.1.3

- **更轻的概览页：** 「详细状态」收起时暂停 LuCI 原生状态组件的轮询，路由器不再被重复查询；展开后恢复。
- **在线设备更准确：** 合并 DHCPv4/v6 租约、Wi‑Fi 关联列表和 ARP 邻居，固定 IP 设备也能显示；Wi‑Fi 设备显示频段和信号强度，名称来自 LuCI 主机信息。
- **IPv6 与流量：** 概览显示外网 IPv6 地址；「实时流量」可选择统计的接口（自动跟随 WAN，或指定 LAN 等）。
- **温度：** 读取所有热区和 hwmon 传感器（CPU、SoC、无线芯片、x86 coretemp），最多显示三项。
- **多语言：** 主题文案改用标准 gettext（`po/`），新增繁体中文；侧栏语言切换列出所有已安装的 LuCI 语言（超过两种时使用下拉框，可选「自动」），不再把其他语言覆盖为英文。
- **下载镜像：** 「Carbon 主题设置」可填写 HTTPS 镜像前缀。只用于下载安装包，版本、大小和 SHA-256 仍以 GitHub 为准；镜像失败自动改用 GitHub。
- **无障碍：** 手机抽屉菜单打开时锁定背景并管理焦点；分段按钮支持方向键；收起的侧栏在触屏上点按展开子菜单，键盘可用 Enter / → 进入、Esc 返回。
- **安装脚本走包管理器：** `carbon-install.sh` 内置签名 APK、IPK 和公钥，通过 apk/opkg 安装，在线升级可用，无需手动导入公钥（APK 在独立密钥目录中验签，不修改 `/etc/apk/keys`）。重新运行即可把旧版脚本安装转为正式安装；`--trust-key` 可同时信任公钥，`--files` 保留原来的复制文件方式。离线且缺少依赖时自动改为复制文件。
- **体积：** 发布包中的 CSS/JS 经过压缩（约小 20%），源码保持可读。

**升级：** 新增的仪表盘数据（Wi‑Fi 关联、ARP、主机信息、全部温度传感器）需要新的 RPC 权限，升级后**退出并重新登录一次**才会显示；未重新登录前仪表盘按原方式工作。

**以前用安装脚本安装、页面提示「请先通过系统包管理器安装一次 Carbon」的设备：** 重新运行一次本版本的 `carbon-install.sh`，之后即可在网页一键升级，无需导入公钥。

**English:** The overview pauses LuCI's own status polling while its details are collapsed. Connected devices now merge DHCPv4/v6 leases, Wi‑Fi stations (band and signal) and ARP neighbours, so static-IP clients appear. The hero shows the WAN IPv6 address, live traffic can follow any interface, and all thermal/hwmon sensors are read. Theme strings use gettext catalogues (`po/`) with a new Traditional Chinese translation, and the language switch lists every installed LuCI language. The updater accepts an optional HTTPS download mirror; metadata and SHA-256 still come from GitHub, with automatic fallback. Accessibility improves for the phone drawer, segmented controls and the collapsed rail on touch and keyboard. `carbon-install.sh` now embeds the signed APK, the IPK and the public key and installs through apk/opkg, so script installs get online updates without importing a key (the APK is verified in a private key directory); rerunning it converts older script-only installs. `--trust-key` also trusts the key for LuCI uploads, `--files` keeps the copy-only mode. Release assets are minified. Log out and back in once after upgrading to grant the new dashboard permissions. Devices that show "install Carbon through the package manager" after a script install: run this release's `carbon-install.sh` once to enable online updates.
