### v1.1.1

- 将「Carbon 更新」统一更名为「Carbon 主题设置」，同步菜单、页面标题、中英文文案和使用说明。
- 左侧菜单改用 Carbon 六边形与中心圆点的单色线框图标，与其他菜单的尺寸、线宽和状态配色一致，简洁与专业模式均生效。
- 沿用原 Carbon APK 签名公钥，升级继续验证签名、SHA-256 和文件大小。

**从 v1.1.0 升级：** 打开「系统 → Carbon 更新」，点击「检查更新」，确认目标为 `1.1.1-r1`，然后点击「一键升级」并确认。完成后刷新页面，入口变为「Carbon 主题设置」。无需重新导入公钥；主题与语言偏好保留。

**English:** Renames Carbon Update to Carbon Theme Settings and uses a monochrome Carbon outline icon matching the other navigation icons in Simple and Pro modes. From v1.1.0, open **System → Carbon Update → Check for updates → Install update**, confirm `1.1.1-r1`, and reload after completion. The existing signing key and signature verification remain in use; theme and language preferences are retained.

**菜单缓存提示：** 升级后若菜单或面包屑仍显示 `Carbon Update` /「Carbon 更新」，请退出并重新登录 LuCI 一次，清除旧会话菜单缓存。无需重新安装或重新导入公钥。

**发布后验证：** 在隔离的 OpenWrt 25.12.6（APK）与 24.10.8（IPK）中，从未经修改的 v1.1.0 正式包，通过 LuCI 网页发现并安装 v1.1.1 正式发布包，均成功升级至 `1.1.1-r1`。APK 签名校验通过；主题与中文配置保留。重新登录后两种模式均显示新名称与线框图标。

**Verification:** Both original v1.1.0 Release packages successfully discovered and installed the published v1.1.1 through LuCI in isolated OpenWrt 25.12.6 (APK) and 24.10.8 (IPK) environments. APK signature verification passed and theme/language settings were preserved. If the old menu name remains, log out and back in once to clear LuCI's session menu cache; no reinstall or key import is needed.
